Esta página trata sobre la política de privacidad de las aplicaciones: Elizaboth (1534359689230418011), Sarissath (1524424473435181078), Manguito (1534359689230418011) que pertenecen al entorno de Mixi dev.
Cuyas aplicaciones funcionan como una misma pero cada una cumple una función diferente.

* Datos recolectados
- Tu ID de discord: Usado para la búsqueda de datos de configuración, juego y sistemas.
- La ID del servidor: Para datos de configuración a nivel de servidor.
- Datos públicos (Como tu avatar, tu apodo, los roles que posees...), estos datos se utilizan para la optimización al ejecutar los comandos y para sistemas de verificación de permisos, si tienes algún rol o el tiempo que tienes en el servidor, estos datos se utilizan para condicionales y comprobaciones en el sistema.
- Datos de juego e información proporcionada para la configuración de los sistemas.

La mayoría de los datos estarán accesibles para el usuario, ya que los sistemas mayormente son CRUD, los cuales cuya información es puede editar manualmente por el usuario.
Estos datos no salen fuera de este entorno, no son comerciados ni compartidos externamente.


* Contenido de mensajes
Los bots pueden leer el contenido de mensajes, el contenido de estos no se guardan en el sistema a excepción de que se esté ejecutando actualmente algún comando que requiera un input (una información).
Un caso de esto es el sistema de gatos, el cual detecta mensajes en un canal en concreto para activar un evento, solo detecta los mensajes y no los guarda en ningún momento.
El input que se coloque en los comandos slash podrán ser leídos por el bot y utilizados para guardar configuración o para condicionales.


Nuestros sistemas intentan usar la mínima información del usuario, la mayoría de los datos son para hacer funcionar las diferentes funcionalidades de los bots.
